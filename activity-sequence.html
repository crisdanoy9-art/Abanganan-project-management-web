ABANGANAN · 12-WEEK PLAN

ACTIVITY SEQUENCING

Activity Sequencing shows the order of the work across the 12-week plan — which phase has to finish before the next one can begin, and which phases run side by side to keep the timeline short.

START
1

PLANNING AND REQUIREMENTS

PHASE 01
  • Define project objectives and scope
  • Identify stakeholders (room seekers, landlords, admin)
  • Analyze the current room-finding process
  • Gather initial requirements from users
  • Define functional and non-functional requirements
  • Identify project risks
2

UI/UX DESIGN

PHASE 02
  • Design the room seeker user flow
  • Design the landlord user flow
  • Design admin dashboard wireframes
  • Design the map-based listing interface
  • Build Figma prototypes
  • Define the visual design system
3

BACKEND AND DATABASE SETUP

PHASE 03
  • Set up the Supabase project (database, auth, storage)
  • Design the database schema / ERD
  • Set up user authentication and roles
  • Set up storage for listing photos
  • Configure the API structure
  • Set up the GitHub repository and environments
4

FRONTEND DEVELOPMENT

PHASE 04 · PARALLEL WITH PHASE 03
  • Develop landlord registration and login
  • Develop listing upload (photos, price, description, amenities)
  • Develop room seeker registration and login
  • Develop listing browsing and detail pages
  • Develop filtering by barangay and price
  • Develop nearest-room search by reference point
  • Develop the private inquiry system
  • Develop landlord listing edit/take-down tools
5

MAP AND LOCATION INTEGRATION

PHASE 05
  • Integrate Google Maps / Mapbox API
  • Enable landlords to pin the exact property location
  • Enable seekers to view listings on a map
  • Implement distance calculation to a reference point
6

ADMIN DASHBOARD

PHASE 06
  • Develop listing moderation tools
  • Develop landlord ownership verification
  • Develop seeker-landlord issue resolution tools
  • Develop the rental trend dashboard
  • Develop reports on popular and underserved areas
7

TESTING AND REVISIONS

PHASE 07
  • Prepare the test plan and test cases
  • Conduct unit and integration testing
  • Conduct usability testing
  • Conduct security testing
  • Fix identified defects
  • Gather feedback and revise
8

DOCUMENTATION AND PITCH PREP

PHASE 08
  • Prepare technical documentation
  • Prepare the user guide
  • Write the pitch video script and outline
  • Prepare slides and visual aids
  • Record and edit the pitch video
  • Final review and submission
END
